# 嵐山核准插畫與分層動畫

工具：內建 imagegen；以使用者核准的嵐山改版草稿作為唯一構圖與畫風參考。所有插畫屬本專案生成素材，沒有引用網路照片。

輸出：public/illustrations/arashiyama/background.webp、train.webp、boat.webp。背景約290 KB，透明火車約32 KB，透明遊船約58 KB，皆納入 PWA 快取。

背景提示：保留核准草稿的完整版面、房屋、車站、竹林、橋、鐵路、河道、步行路線及交通文字；僅移除鐵軌上的紅黃火車、河道上的船與其水花，以及「重播」控制，補回被遮住的鐵軌、水面與紙色。

火車提示：以核准草稿為畫風參考，生成一列獨立、朝左、水平側視的紅黃嵯峨野觀光火車；左側車頭與右側兩節車廂，奶油白窗戶、暖棕色外框、繪本紙感，真正透明背景，不含鐵軌、地面、文字或陰影背景。

遊船提示：以核准草稿為畫風參考，生成朝右、水平側視的保津川木造遊船；蜂蜜黃色低船身、奶油白珊瑚條紋篷頂、兩位旅人與戴斗笠的船夫，真正透明背景，不含水面、水花、文字或其他景物。

實作保留外部 HTML 標題，SVG 裁去背景內重複標題。動畫從站外軌道至龜岡停住，延遲0.7秒後遊船出發；進入可視範圍後播放一次，元件卸載時清理計時，重新進入該頁便重新播放。沒有重播按鈕。減少動態效果與放大檢視顯示終點靜態狀態。
